# Página del Día de la Madre para Viviana 💛

## Qué incluye
- Botón de sorpresa que revela el contenido.
- Carta personalizada para Viviana.
- Contador animado hasta **6.147 días juntos**.
- Las 3 fotos proporcionadas.
- Ramo de flores amarillas, rojas y naranjas creado con CSS.
- Botón para escuchar **“Mi novia se me está poniendo vieja” — Ricardo Arjona** en YouTube.
- Diseño adaptable a celular y computadora.

## Abrirla en tu computadora
1. Descomprimí el ZIP.
2. Abrí `index.html` con Chrome, Edge o Firefox.
3. No hace falta instalar nada.

## Publicarla gratis y compartir un enlace (GitHub Pages)
1. Creá una cuenta en https://github.com si no tenés una.
2. Creá un repositorio nuevo, por ejemplo: `dia-madre-viviana`.
3. Subí **todo el contenido** de esta carpeta, manteniendo la carpeta `imagenes`.
4. En GitHub entrá a **Settings → Pages**.
5. En "Build and deployment", elegí **Deploy from a branch**.
6. Seleccioná la rama `main` y la carpeta `/ (root)`.
7. Guardá y esperá unos minutos.
8. GitHub te mostrará una dirección parecida a:
   `https://TU-USUARIO.github.io/dia-madre-viviana/`

Ese es el enlace que podés compartir por WhatsApp.

## Sobre la canción
Por derechos de autor, el proyecto no incluye una copia del audio de Arjona.
El botón de música abre una búsqueda de YouTube para esa canción. Así podés escucharla desde la plataforma correspondiente.

Si tenés permiso/licencia para usar un archivo de audio, podés agregarlo como `musica.mp3` y convertir el botón en un reproductor local.
